## Quick Start

### 1. Start the database

```bash
docker compose up -d
```

### 2. Run the backend

```bash
cd backend
cp .env.example .env    # adjust if needed
npm install
npm run start:dev       # runs on http://localhost:3000
```

API docs: [http://localhost:3000/api/docs](http://localhost:3000/api/docs)

### 3. Run the frontend

```bash
cd frontend
npm install

```
